**🎯 Focus**
- **Web & API** — broken access control (IDOR/BOLA), SSRF, injection, payment & business-logic flaws
- **Smart contracts (EVM)** — oracle manipulation, upgradeability & storage, reentrancy, fork patch-gap analysis
- **Dark corners** — client-side payment/auth flows, SDKs, MCP & agent endpoints

**🧪 How I work**

- Honest severity: if it doesn't touch funds or accounts, I say so
